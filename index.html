M2 Giant Group Operations & Asset Management System

Group project · 90% final mark

A business management application built for a real-world tree felling and vegetation management company, developed collaboratively in C# WinForms against a SQL Server backend. Covers the full operational loop: client intake, job requests,quoting, scheduling and calendar assignment, staff and asset allocation, and site photo documentation with before/after tagging.

  • Developed an automated quotation generation system that calculates service costs, travel fees, VAT, and produces professional PDF quotations
  • Invoicing and income/expense reporting via Crystal Reports
  • Dynamic photo gallery with thumbnail previews
  • Integrated an interactive Leaflet.js map into a C# Windows Forms application using WebView2, enabling address search, draggable map markers, and automatic GPS coordinate capture

SYS — 02

Fandom Factory — Multi-threaded Merchandise Store System

Team of 7 · 94% final mark

A concurrent inventory and order-processing system written in C++, simulating simultaneous merchandise purchases without corrupting shared state. Synchronisation was handled with mutexes and smart pointers to prevent race conditions, overselling, and inconsistent stock during simultaneous transactions, built on a thread-safe, memory-safe object-oriented architecture.
