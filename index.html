01 Systems

SYS — 01

M2 Giant Group Operations & Asset Management System

group project

A business management application built for a tree services company, developed collaboratively in C# WinForms against a SQL Server backend. Covers the full operational loop: client intake, job requests, scheduling and calendar assignment, staff and asset allocation, and site photo documentation with before/after tagging.

  • Quote generation using Haversine-distance travel-fee calculation and 15% VAT
  • Invoicing and income/expense reporting via Crystal Reports
  • Site photo gallery with per-thumbnail error isolation
  • South African phone/email validation and coordinate bounding-box checks
  • Leaflet map embedded via WebView2 for job-site locations

SYS — 02

Multi-threaded Merchandise Store System

individual project

A concurrent store-management system written in C++, handling simultaneous transactions and inventory operations across threads without corrupting shared state. Built as an exercise in synchronisation primitives, race-condition avoidance, and designing for concurrent access from the ground up rather than bolting it on afterward.

C++MultithreadingSTLSynchronisation
SYS — 03

Personal Error Log & Fuzzy Search Tool

in exploration

An early-stage concept for a developer productivity tool: a searchable personal log of past errors and their fixes, with fuzzy/semantic matching so a half-remembered stack trace can still surface the right note. Scoped as an MVP around local SQLite storage, targeting VS Code as the primary surface.
